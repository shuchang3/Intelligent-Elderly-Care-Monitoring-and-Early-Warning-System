# 视界无疆实施交接与验收

日期：2026-09-01。版本：1.1.0-integration。**这是已经写入代码并完成部分实机验收的单机联调版本，不是“七个阶段全部通过”的结项证明。**

## 本次真正改变了什么

1. 从两套互不相连的后端，改为浏览器→Flask→Java→MySQL。Flask保留页面和会话，Java成为账户、档案、告警和权限依据；原硬编码管理员/家属登录已经移除。
2. 新建 `backend` Java21/Spring Boot工程，使用独立 `elder_care_dev`，实现事务入库、并发幂等、处理记录、鉴权媒体、原生WebSocket票据、人员/人脸、区域、统计和扩展接口。旧ZIP和旧库不覆盖，**没有把新表当成旧库自动迁移方案**。
3. 统一请求、错误、CSRF、服务端会话、Cookie和角色控制。照片、画面、录像不再通过公开目录绕过认证；长期JWT不进浏览器URL或localStorage。
4. 真实分页筛选、处理、手动刷新、统计、当前页CSV导出；区域实际绘制和编辑，版本确认；人员新增、编辑、照片状态、停用；管理员创建家属账户并绑定老人。
5. 算法懒加载，AI关闭可单独启动页面；每路独立采集，每个track独立状态机；人脸库锁保护和版本同步；真实事件时间与单调计时分开；未知摔倒配置报错。
6. 独立情绪分析队列与2秒节流；默认持续30秒悲伤、观测缺失5秒重置；规则参数只是工程初值。危险区按脚底中心点、持续进入/离开判断；不伪造跌倒概率。
7. 持久化上报队列：UUID重试、401/403暂停、网络退避、无效数据失败记录、容量/磁盘上限提示。录制前约10秒、后20秒并关联事件，实际MP4鉴权播放。
8. 单摄像头DeepSORT轨迹、情绪采样与日聚合、老人/义工接近候选及人工复核、告警等级、手机响应式页面及默认关闭的Web Push发送器已写入工程。
9. 加入环境检查、独立建库、启动/停止脚本和OpenAPI导出。脚本记录PID和日志，只停止本项目进程树，不自动删除虚拟环境、导入旧DROP脚本、修改防火墙或开放公网。

## 后端交接清单

- 入口 `com.eldercare.platform.Application`，JDK21，`backend/pom.xml`，产物 `backend/target/elder-care-backend.jar`，与manifest的SHA256核对。
- `schema.sql`是新版空库结构；`scripts/init-db.ps1`执行建库+随机初始账号。没有任何自动从旧elder/旧event表搬迁数据的代码。旧库迁移必须先取得字段映射、备份并在副本演练。
- SQL表名、认证、JSON、照片/录像、配置ack与旧ZIP有差异。后端同学可继续维护此实现，也可在旧分层架构中等价实现，但**必须以自动测试与接口契约保持一致**，不能只改文档不改运行包。
- 首轮Redis关闭；后续可配置 `REDIS_ENABLED=true`、REDIS_HOST/PORT/PASSWORD，当前仅缓存非家属计数。已测关闭与连接异常降级，未安装Redis服务并测成功命中；启用前要补这一项。
- 真实凭据在 `.env.local`；正式运行不要长期使用数据库root，安排最小数据库权限、密码轮换、媒体清理与备份。此版本绑定回环地址，不是公网生产交付。
- 升级必须记录版本号、源码校验、JAR校验、数据变更、回滚及测试结果，不将旧Apifox导出继续当作本版文档。

## 算法交接清单与已知限制

- 实际环境记录见 `requirements-ai-observed.lock.txt`，纯网页可复现记录见 `requirements-web.lock.txt`。不要无条件重新安装旧requirements覆盖现有可运行环境。
- YOLO权重来自给定文件，情绪权重使用现有DeepFace缓存。启动检查缺失模型时报告错误，YOLO/情绪模块不偷偷下载替代权重。权重文件校验在manifest中记录。
- DeepSORT目前用颜色直方图作关联特征；仍须测试交叉、遮挡、衣着相似的身份切换。人脸尚未识别到时personCode为空，家属不能看无可靠归属的公共事件。
- 情绪结果只代表视觉模型分类，不能称作诊断；规则确认30秒不计入“事件确认后2秒送达”的性能目标。
- 录像以5fps采集缓存，窗口为近似10+20秒。掉帧、初启不足、设备离线/进程强停会使录像不完整。应在现场核对编码可播放、时间范围、重叠事件、磁盘压力。
- 现场提示使用电脑系统提示音，默认关闭；不是已经接通了养老院广播或声光告警设备。
- 持久化队列有界，达到上限会提示丢失风险；失败记录需人工检查。当前没有自动清除正式历史媒体的保留策略，长期运行必须补容量、备份、保留期限和清理演练。
