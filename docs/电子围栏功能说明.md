# 电子围栏功能模块 - 使用指南

## 功能概述

电子围栏模块基于北斗RTK定位手环，实现老人活动范围监控和越界告警功能。

### 核心特性

- ✅ **多边形安全区**：支持在地图上绘制任意形状的安全区域
- ✅ **两级告警**：短暂离开（30秒）→ WARNING，长时间离开（120秒）→ CRITICAL
- ✅ **实时位置追踪**：每5秒更新一次位置，显示最后已知位置
- ✅ **轨迹记录**：保存30天历史轨迹，支持回放查询
- ✅ **百度地图集成**：可视化展示围栏、位置和轨迹

## 快速开始

### 1. 数据库初始化

重新运行数据库初始化脚本以创建新表：

```powershell
.\scripts\init-db.ps1
```

这会创建以下新表：
- `geofence` - 电子围栏配置
- `person_device_binding` - 老人与手环绑定
- `location_history` - 位置历史记录

### 2. 启动服务

```powershell
# 启动Java后端
.\scripts\start-backend.ps1

# 启动AI服务（包含地理围栏监控器）
python ai_service.py
```

### 3. 配置百度地图API Key

编辑 `templates/geofence/map.html`，找到第78行：

```javascript
<script type="text/javascript" src="https://api.map.baidu.com/api?v=3.0&ak=YOUR_BAIDU_MAP_AK"></script>
```

将 `YOUR_BAIDU_MAP_AK` 替换为你的百度地图AK（申请地址：https://lbsyun.baidu.com/apiconsole/key）

## 使用流程

### 步骤1：创建测试老人

访问 http://localhost:5000/persons 或通过API：

```bash
curl -X POST http://localhost:8080/api/v1/persons \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "personCode": "ELDER-001",
    "name": "张三",
    "personType": "ELDER"
  }'
```

### 步骤2：绑定北斗设备

```bash
curl -X POST http://localhost:8080/api/v1/person-device-bindings \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "personCode": "ELDER-001",
    "deviceId": "BEIDOU-DEVICE-001"
  }'
```

### 步骤3：绘制电子围栏

1. 访问 http://localhost:5000/geofence/map
2. 点击"绘制新围栏"按钮
3. 在地图上点击多个点形成多边形（至少3个点）
4. 双击完成绘制
5. 填写围栏信息并保存

**建议测试区域**：50m × 50m 的正方形

### 步骤4：模拟位置数据（测试用）

运行测试脚本模拟老人移动：

```powershell
python scripts/test-geofence.py
```

该脚本会：
1. 自动创建测试老人和设备
2. 创建50m×50m的测试围栏
3. 模拟老人从围栏内走到外面的过程
4. 触发WARNING和CRITICAL告警
5. 显示位置历史

### 步骤5：查看告警和轨迹

- **实时告警**：http://localhost:5000/alert/real
- **历史告警**：http://localhost:5000/alert/history
- **轨迹查询**：通过API `/api/v1/tracks/{personCode}`

## API接口说明

### 电子围栏管理

#### 创建围栏
```
POST /api/v1/geofences
Content-Type: application/json

{
  "fenceCode": "FENCE-001",
  "fenceName": "养老院活动区",
  "points": [[116.397, 39.908], [116.398, 39.908], [116.398, 39.909], [116.397, 39.909]]
}
```

#### 查询围栏列表
```
GET /api/v1/geofences
```

#### 更新围栏
```
PUT /api/v1/geofences/{fenceCode}
Content-Type: application/json

{
  "fenceName": "新名称",
  "enabled": true,
  "points": [[...]]
}
```

#### 删除围栏
```
DELETE /api/v1/geofences/{fenceCode}
```

### 设备绑定

#### 绑定设备
```
POST /api/v1/person-device-bindings
Content-Type: application/json

{
  "personCode": "ELDER-001",
  "deviceId": "BEIDOU-001"
}
```

#### 解绑设备
```
DELETE /api/v1/person-device-bindings?personCode=ELDER-001
```

### 位置数据接收

#### 接收北斗位置更新
```
POST /api/v1/location/update
X-AI-Key: YOUR_AI_KEY
Content-Type: application/json

{
  "pointNo": "uuid-here",
  "deviceId": "BEIDOU-001",
  "personCode": "ELDER-001",
  "longitude": 116.3975,
  "latitude": 39.9085,
  "sampleTime": "2026-09-05T14:30:00",
  "accuracy": 5.0,
  "altitude": 50.0,
  "speed": 1.2,
  "direction": 45.0
}
```

响应：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "insideFence": true,
    "fenceCode": "FENCE-001"
  }
}
```

### 轨迹查询

#### 查询历史轨迹
```
GET /api/v1/tracks/{personCode}?startTime=2026-09-01T00:00:00&endTime=2026-09-05T23:59:59
```

#### 查询最后已知位置
```
GET /api/v1/location/last-known/{personCode}
```

## 告警机制

### 告警级别

| 级别 | 触发条件 | 说明 |
|------|---------|------|
| WARNING | 离开围栏30秒 | 短暂离开，提醒护工注意 |
| CRITICAL | 离开围栏120秒 | 长时间离开，通知管理员和家属 |

### 告警推送

- **WebSocket实时推送**：管理员和护工立即收到
- **浏览器通知**：如果启用了Web Push
- **事件记录**：保存到`event`表，可在历史告警中查看

### 告警数据结构

```json
{
  "eventNo": "uuid",
  "eventType": "GEOFENCE_EXIT",
  "cameraCode": "GPS",
  "personCode": "ELDER-001",
  "eventTime": "2026-09-05T14:35:30",
  "description": "老人离开安全区 - 长时间离开",
  "confidence": 1.0,
  "scoreType": "CRITICAL",
  "location": "116.398500,39.909500"
}
```

## 真实手环对接

### 手环要求

- 支持北斗B1/B2/B3三频信号
- RTK高精度定位模块
- 4G通信模块
- 能够HTTP POST上报位置数据

### 数据格式

手环应每5秒发送一次HTTP POST请求到：

```
POST http://YOUR_SERVER_IP:5002/api/v1/location/update
X-AI-Key: YOUR_AI_SERVICE_KEY
Content-Type: application/json

{
  "pointNo": "UNIQUE_POINT_ID",
  "deviceId": "DEVICE_SERIAL_NUMBER",
  "personCode": "关联的老人编号",
  "longitude": 116.3975,
  "latitude": 39.9085,
  "sampleTime": "2026-09-05T14:30:00",
  "accuracy": 5.0
}
```

### 注意事项

1. **AI_SERVICE_KEY**：从`.env.local`文件获取
2. **时间格式**：ISO 8601格式，精确到秒
3. **坐标系统**：WGS-84坐标系（GPS标准）
4. **频率控制**：建议5秒一次，避免服务器压力

## 常见问题

### Q1: 地图不显示？

检查：
1. 百度地图AK是否正确配置
2. 浏览器控制台是否有错误信息
3. 网络连接是否正常

### Q2: 位置更新但没有告警？

检查：
1. 围栏是否已启用（`enabled=true`）
2. 设备是否正确绑定到老人
3. AI服务是否正常运行
4. 查看AI服务日志：`runtime/logs/backend.out.log`

### Q3: 如何调整告警阈值？

修改 `algorithm/geofence_monitor.py` 中的常量：

```python
self.WARNING_THRESHOLD = 30.0   # 改为其他秒数
self.CRITICAL_THRESHOLD = 120.0  # 改为其他秒数
```

重启AI服务生效。

### Q4: 轨迹数据保留多久？

默认保留30天。可以手动清理旧数据：

```sql
DELETE FROM location_history WHERE sample_time < NOW() - INTERVAL 30 DAY;
```

或设置定时任务自动清理。

### Q5: 室内定位怎么办？

根据需求，室内不依赖北斗定位，而是通过摄像头监控。因此：
- 手环在室内可能无信号或精度差
- 系统只显示最后已知位置和时间
- 室内活动由视频监控覆盖
